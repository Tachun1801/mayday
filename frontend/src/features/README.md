# Web features

- [auth/](auth/README.md): session, login/signup, profile/password.
- [patients/](patients/README.md): tìm kiếm, tiếp nhận mới/cũ/lần đầu.
- [medical-records/](medical-records/README.md): hồ sơ/phiên, editor, đơn/kết quả, tổn thương.
- [patient-portal/](patient-portal/README.md): own records, UAS và ảnh/tổn thương.
- [media/](media/README.md): attachment/upload/private viewer dùng lại giữa workspace.
- [admin/](admin/README.md), [facilities/](facilities/README.md), [catalogs/](catalogs/README.md): quản trị theo quyền.
- [system/](system/README.md): HTTP liveness.

Feature sở hữu fields/payload và màn hình; shared lo request/session/UI. [API contract](../../../doc/current-api.md) là nguồn route/policy hiện hành.
